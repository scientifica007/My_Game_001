# حُماة الواحة — Oasis Defenders

لعبة دفاع عن الأبراج (Tower Defense) صغيرة ومكتملة باللغة العربية، تعمل مباشرة في المتصفح. **لا تحتاج إلى تسجيل حساب أو إنترنت أو حزم برمجية.**

## التشغيل

- **مباشرة من الحاسوب:** نزّل الملف [index.html](index.html)، ثم افتحه باستخدام Firefox أو Chromium أو Chrome.
- **على الويب (بعد تفعيل GitHub Pages):** [تشغيل حُماة الواحة](https://scientifica007.github.io/My_Game_001/).

> ملاحظة: رابط GitHub Pages لا يصبح متاحًا تلقائيًا بمجرد رفع الملفات. يجب تفعيله من **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**. يستغرق النشر عادةً بضع دقائق.

## هدف اللعبة

احمِ الواحة من **خمس موجات** من الأعداء. استخدم الذهب لبناء أبراج السهام أو القذائف على الخانات الرملية خارج الطريق، وقم بترقيتها أو بيعها حسب الحاجة.

| الأداة | الوظيفة |
|---|---|
| برج السهام — 55 ذهب | هجوم سريع على عدو واحد |
| برج القذائف — 95 ذهب | هجوم أبطأ يلحق الضرر بمجموعة |
| ترقية البرج | تحسين مستوى البرج المحدد (حتى المستوى 3) |
| بيع البرج | استرداد جزء من التكلفة |
| بدء الموجة | إطلاق الموجة التالية |
| إيقاف / متابعة | إيقاف المعركة مؤقتًا |
| السرعة ×1 / ×2 | تبديل سرعة المعركة |
| لعبة جديدة | إعادة الجولة من البداية |

**الاختصارات:** `1` برج السهام؛ `2` برج القذائف؛ `Space` بدء الموجة؛ `P` إيقاف/متابعة؛ `F` تبديل السرعة.

## المتطلبات التقنية

- HTML وCSS وJavaScript فقط؛ **ملف واحد** من دون تبعيات خارجية.
- واجهة عربية من اليمين إلى اليسار، وتصميم متجاوب للهواتف والحواسيب.
- تشغيل اللعبة والرسم باستخدام Canvas.
- تخزين عدد الانتصارات وأفضل نتيجة محليًا فقط، إذا سمح المتصفح بذلك.
- لا ترسل اللعبة معلومات إلى خادم.

## اختبارات المشروع

يحتوي المستودع على اختبارات بسيطة تُنفّذ عبر GitHub Actions تلقائيًا عند كل Push أو Pull Request.

محليًا (مع Node.js 20 أو أحدث):

```bash
node --test tests/game.test.mjs
```

تتحقق الاختبارات من سلامة صياغة JavaScript، ووجود عناصر التحكم الأساسية، وعدد الموجات، ومتطلبات التشغيل دون تبعيات.

## نشر اللعبة عبر GitHub Pages

1. افتح **Settings → Pages** في المستودع.
2. اختر **Deploy from a branch**.
3. اختر الفرع **main** ثم المجلد **/(root)** واضغط **Save**.
4. بعد نجاح النشر، افتح https://scientifica007.github.io/My_Game_001/ .

## بنية الملفات

```text

```

المشروع تجربة صغيرة مستقلة، وليس تطبيقًا متعدد المستخدمين أو لعبة تتطلب خادمًا.
